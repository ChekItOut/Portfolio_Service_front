# Curvify Portfolio

This contains everything you need to run the app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1aa7ZQExVbvx8Acq5It9DAWyvVbXAyXKx

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

Portfolio data is stored in the browser's `localStorage`. No backend server or login setup is required.
